# Examples

Values files that double as the chart's test inputs.

- `minimal.yaml`, `app-secrets.yaml`, `app-db-secrets.yaml`: single-file
  examples of the smallest app and of secret injection.
- `myapp/`: the reference `.k8s/` layout an app ships (umbrella `Chart.yaml`,
  `values.base.yaml`, one file per environment, `values.preview.yaml`).
- `rendered/`: `helm template` output of every example, generated by
  `scripts/regen.sh` and checked by CI. Read these to see exactly what a
  values file produces.
